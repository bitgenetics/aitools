# @bitgenetics/aitools-core

Shared types, schemas, path helpers, and utilities for **AITools**.

Most users should install the CLI instead:

```bash
npm install -g @bitgenetics/aitools-cli
```

This package is a dependency of `@bitgenetics/aitools-cli` and of the HTTP registry server. Import it only if you are building tooling against the AITools library API.

> **Full docs:** [github.com/bitgenetics/aitools](https://github.com/bitgenetics/aitools)

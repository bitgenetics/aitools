# @bitgenetics/aitools-cursor

Cursor Agent CLI helper used by **AITools**. Loads multi-root `.code-workspace` folders into `agent --add-dir` roots.

Most users get this transitively via:

```bash
npm install -g @bitgenetics/aitools-cli
```

Optional direct binary:

```bash
npx @bitgenetics/aitools-cursor --help
```
